## 🎯 产品定位

面向自媒体人、中小商家的 **AI 多平台运营工具**。不是简单的内容生成器，而是帮你**自动完成从选题、创作、优化到多平台发布的全流程**。

### 核心价值

| 传统方式 | AI运营帮 |

| 逐个平台写文案、配图、排版 | AI 一次生成，多平台自动适配 |
| 手动登录每个平台发布 | 矩阵账号管理，一键多平台分发 |
| 内容生成和发布是两个工具 | 自动流水线，从创作到发布一条龙 |

## 📦 核心功能

### 🤖 自动流水线（核心亮点）

- **AI 自主规划**：输入目标，Agent 自动拆解为多步骤执行
- **一条龙执行**：内容生成 → 内容优化 → 字数精简 → 多平台自动发布
- **实时运行日志**：终端风格日志，每一步执行状态实时可见
- **发布汇总报告**：执行完成后显示成功/失败统计、各平台详情
- **定时执行**：支持 cron 表达式定时触发
- **立即执行**：支持手动触发，方便测试

### 📝 内容创作中心

- **文案创作**：AI 生成爆款文案，支持多平台格式适配
- **图片生成**：AI 文生图，多模型优雅降级
- **视频生成**：AI 视频生成
- **图文创作**：图文混排，适合小红书/头条
- **身份（人设）管理**：自定义创作风格，AI 按人设输出
- **知识库**：本地文档管理，AI 创作时自动参考

### 📤 发布中心

- **5 大平台支持**：抖音、小红书、快手、B站、今日头条
- **多账号发布**：同一平台可多选账号，按顺序依次发布
- **自动字数精简**：正文超出平台限制时自动智能精简（默认开启）
- **发布队列**：待发布内容统一管理，支持一键填入
- **发布历史**：发布记录可追溯，成功/失败状态清晰
- **实时日志**：发布过程实时显示，方便排查问题

### 🎭 矩阵账号

- **多平台多账号**：每个平台可添加多个账号，独立登录态
- **扫码登录**：浏览器扫码登录，登录态本地保存


### 配置环境变量（重要，先读）

**设计原则：各子包自管 env，框架原生加载，零脚本零依赖。** Next / Vite 原生读取**各自目录**下的 `.env`，且 `.env.local` 优先级最高——无需任何注入脚本或 npm 包。`.env`（含真实 key）入库，dev/main 两分支内容**保持一致**；`.env.local` 被 `.gitignore` 忽略，是**本地覆盖层**，合并代码永远不会把本地差异带到 main。

文件清单（每个子包三件套，无根目录 env）：

| 文件 | 内容 | 入库 | 读取方 |
|------|------|------|--------|
| `apps/backend/.env` | Web 生产值（Supabase / 站点 / 下载 / DUIX / Inngest） | ✅ | Next.js 原生 |
| `apps/backend/.env.local` | Web 本地覆盖（localhost / GitHub 下载） | ❌ | Next.js 原生（优先） |
| `apps/backend/.env.example` | Web 模板（占位值） | ✅ | 参照 / 复制为 `.env.local` |
| `apps/desktop/.env` | 桌面端生产值（VITE_* 全套） | ✅ | Vite 原生；CI 打包时被 Secrets 覆盖 |
| `apps/desktop/.env.local` | 桌面端本地覆盖（localhost） | ❌ | Vite 原生（优先） |
| `apps/desktop/.env.example` | 桌面端模板（占位值） | ✅ | 参照 / 复制为 `.env.local` |

新环境只需建本地覆盖层（复制模板，只留差异值；与生产相同的 key 可省略，自动继承）：

```bash
cp apps/backend/.env.example apps/backend/.env.local
cp apps/desktop/.env.example apps/desktop/.env.local
```

加载顺序（框架原生，本地优先）：Next.js `.env.local > .env.development > .env`；Vite `.env.development.local > .env.development > .env.local > .env`。

**运行 / 构建**（根 scripts 一键，也可直接进子包目录跑）：

```bash
npm run dev:web        # Web 开发（localhost:3000）
npm run dev:desktop    # 桌面端开发（vite 5173 + Electron 窗口 + 热更新）
npm run build:web      # Web 生产构建
npm run build:desktop  # 桌面端生产构建
```

> 注意：Next 只消费 `NEXT_PUBLIC_*`，Vite 只消费 `VITE_*`。同一个值（如 Supabase URL）在 `apps/backend/.env` 用 `NEXT_PUBLIC_` 前缀、在 `apps/desktop/.env` 用 `VITE_` 前缀各写一行，改一处需两处同步。

#### Web 端变量（`apps/backend/.env` + `.env.local`）

|------|------|

| `NEXT_PUBLIC_DESKTOP_DOWNLOAD_MAC` | macOS 安装包下载地址 |

| `NEXT_PUBLIC_DESKTOP_VERSION` | 桌面端当前版本号 |
| `NEXT_PUBLIC_DOWNLOAD_BAIDU_URL` | 百度网盘备用下载地址 |

#### 桌面端变量（`apps/desktop/.env` + `.env.local`）

| 变量 | 说明 |
|------|------|
| `VITE_SUPABASE_URL` | Supabase 项目地址 |
| `VITE_SUPABASE_ANON_KEY` | Supabase 匿名 key |
| `VITE_ZHIPU_API_KEY` | 智谱 AI API Key |

#### CI / 云主机补充说明

- **桌面端 CI 打包**：GitHub Actions 通过 Secrets 注入环境变量，不影响仓库。
- **云主机部署**：`git pull` 不会覆盖未跟踪的 `.env.local`；无 `.env.local` 时走 `.env` 默认值。
- **改默认值**：只改各包入库的 `.env`，并在 dev / main 两分支同步提交，保持一致。

### 插件特点

- **不用 AI**：纯 DOM 操作 + Playwright，稳定可靠
- **易维护**：平台改版只需更新对应插件，不影响其他平台
- **统一接口**：所有插件实现相同的 `publish()` 接口

## 🔑 关键业务逻辑

### 实名认证
- 用户提交：姓名、手机号、身份证号
- 前端校验：手机号格式、18 位身份证校验码算法
- 认证后：字段锁定不可修改
- 奖励：认证成功赠送 100 积分

### 积分系统
- 积分来源：注册赠送、实名认证奖励、邀请奖励、佣金积分
- 积分用途：开通 VIP、转账给好友
- 100 积分 = 1 元
- 单笔转账上限：500 积分，单日上限：1000 积分

### 订阅系统
- 免费版：发布/文案/视频/图片/流水线各 5 次/天
- VIP：不限量，日付 ¥1、周付 ¥7（9折）、月付 ¥24（8折）
- 支付方式：RMB（扫码+人工审核）、积分（自动开通）

### 分销系统
- 邀请好友完成实名认证，双方各得 100 积分
- 好友 RMB 支付，推广者得 10% 佣金（可提现）
- 好友积分支付，推广者得 10% 积分（可转让）
- 注册时填写邀请码才绑定上级关系

### 自动流水线
- 执行步骤：内容生成 → 内容优化 → 字数精简 → 多平台发布
- 发布时复用发布中心的插件，不重复开发
- 平台之间间隔 2 秒，避免被风控
- 实时运行日志 + 发布汇总报告
